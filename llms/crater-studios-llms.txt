# Crater Studios

> Crater Studios is an AI-native game studio building core AI systems for game design, decision making, and live operations, trained on real player behavior in production environments. It ships live games as production laboratories for its agent platform. Crater Studios publishes no public API, developer portal, documentation, or SDKs as of 2026-07-20.

## About

- [Crater Studios platform](https://craterstudios.ai): AI-native game infrastructure — GDD Maker, live-telemetry decision engine, automated playtesting, moderation, and localization agents.
- [Crater Studios Games](https://www.craterstudiosgames.com): the studio's game portfolio — action RPGs, extraction shooters, and roguelike deckbuilders.

## Playable agent prototypes

Browser prototypes published by Crater Studios as evidence that its design agents can produce working core loops.

- [GDD Maker](https://gddmaker.craterstudios.ai): Crater's game director agent, turning concepts into production-ready game design documents.
- [Doomspire Game Director](https://doomspireagent.craterstudios.ai): game director agent for Doomspire.
- [Dr Decision Engine](https://drdecisionengine.craterstudios.ai): conversational decision engine over live telemetry (Dwarven Realms).
- [Balatro Clone](https://balatro.craterstudios.ai): poker roguelike deckbuilder prototype.
- [Spell Forge](https://spellforge.craterstudios.ai): prototype.
- [Spiderfall Protocol](https://spiderfall.craterstudios.ai): prototype.
- [Micro City](https://microcity.craterstudios.ai): city builder prototype.
- [Terraform Colony](https://terraform.craterstudios.ai): space idle tycoon prototype.
