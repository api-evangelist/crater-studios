# Crater Studios

Crater Studios is an AI-native game studio that builds core AI systems for game design, decision making, and live operations, trained on real player behavior in production environments. The company uses its own live game launches as production laboratories, shipping titles such as Dwarven Realms, Gravebound, and Doomspire on Steam while building agentic tooling around them — a GDD Maker that turns raw concepts into production-ready game design documents, a conversational decision engine wired to live telemetry, automated playtesting agents, content moderation, and localization.

- Platform: https://craterstudios.ai
- Games: https://www.craterstudiosgames.com

Backed by: a16z

## API surface

As of the 2026-07-20 enrichment pass, Crater Studios publishes **no public API**, developer portal, documentation, API reference, SDKs, CLI, MCP server, or machine-readable specification. All five probed `/.well-known/` discovery paths return 404, and every path on craterstudios.ai resolves to the same single-page-app shell. Crater's AI systems are internal platform infrastructure rather than a developer product.

This repo therefore carries identity and probed domain-security posture only.
